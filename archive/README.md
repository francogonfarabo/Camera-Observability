# Archive

Superseded prototypes. They are still built and still deployed so old links do
not break, and each one carries a banner saying it is archived. **None of them
is maintained.** The current board is `/index.html`.

| | what it tested | why it was dropped |
|---|---|---|
| `tone.html` | hue and saturation separating the three center states | colour alone is not an encoding; the current board separates by silhouette as well |
| `nested.html` | one square per center in the overview, always | does not survive past a few hundred centers — the overview now changes zoom instead |
| `fleet.html` | camera health at account altitude, reached by a header toggle | the altitude change belongs in the overview, not in a second screen |

Sources are in `../src/archive/`.
